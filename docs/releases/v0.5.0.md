# v0.5.0 · 登录、横轴与六区拖拽

发布日期：2026-11-05

本版处理桌面登录持久化、手机时间轴选中态、删除同步、手机端导航、GitHub 头像、提供商选择器、横向时间轴、六区拖拽、桌面提醒隐藏与标题栏设置菜单。

## 修复与改进

- **桌面登录持久化**：Wails 的 WebView2 数据目录从 `%APPDATA%\[可执行文件名]` 固定为 `%APPDATA%\LanshanMoments`。启动时按版本号寻找旧目录并迁移，必要时复制；更新程序后 GitHub 登录、API Key、布局与本地日程不会再像新安装一样丢失。
- **手机日期选中修复**：触摸点击日期后浏览器保留 `:hover`，奶油色 hover 表面覆盖了选中日期的浅色文字。现在选中态与 `:hover` / `:focus-visible` 都保持深底浅字，日期和星期清晰可见。
- **删除同步**：删除日程写入 `deletedAt` 墓碑，并在已连接 GitHub 时立即自动同步。同步冲突仍按事件级 LWW 合并；撤销时生成新的 `updatedAt` 与 `rev`，避免被云端旧墓碑覆盖。
- **手机四栏导航**：周表 / 时间轴 / 添加 / 我的等权重。添加日程改为内联页面，不再打开抽屉；我的改为内嵌设置页，不再打开弹窗；整理箱仍通过悬浮按钮/页头按钮打开。
- **GitHub 头像**：连接 GitHub 后保存 `avatarUrl` 到设置；桌面标题栏同步按钮显示头像，「多设备同步」页显示账号卡；旧设置没有头像时使用 `github.com/<owner>.png` 兜底。
- **主题化提供商选择**：模型提供商从原生 `<select>` 改为应用内玻璃选择弹层（桌面居中、手机底部展开），不会再出现系统默认主题的原生菜单。
- **横向时间轴**：电脑端时间轴改为横向时间轴：08:00–23:00 沿 X 轴、垂直网格线、事件按重叠泳道排列，支持左右滚动；手机端保持纵向时间轴。独立时间轴窗口同样横排。
- **标签排序与默认布局**：左右拖动标签页可调整组内顺序；首次启动布局为左侧添加/整理，右侧时间轴在上、周概览在下。
- **六区拖拽**：目标小窗口提供标题、左、右、上、下、正中六个判定区。
  - 标题：合并为标签页，优先显示被拖动标签；
  - 四边：目标切半，拖动窗口占据判定方向；
  - 正中：交换两个窗口的位置（标签拖拽交换标签，组拖拽交换整组内容）。
  - 只有拖出应用视口才独立成原生窗口；在标题栏、顶栏或应用内空白处松手不改变布局。合并/切半/交换都有预览动画，中心交换有脉冲与 `⇄` 动画。
- **桌面隐藏提醒**：桌面设置只保留模型接口 / 多设备同步 / 数据；提醒 tab 仅手机端显示。
- **标题栏设置菜单**：在「应用 编辑 窗口」右侧新增「设置」，展开模型接口、多设备同步、数据三项；移除原来的浮动设置窗口，设置以模态玻璃面板打开。

## 仍未包含

- 六区拖拽针对主窗口内的停靠小窗口；已独立的原生窗口之间仍通过主窗口收回，不直接互相合并。
- 横向时间轴按重叠泳道排列，极窄窗口需要左右滚动；手机保持纵向。
- 桌面端保留通知代码但隐藏入口，提醒功能仍以 Android 为主。
- 布局快照仍只保存在本机，不随 GitHub 同步。
