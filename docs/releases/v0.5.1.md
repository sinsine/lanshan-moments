# v0.5.1 · 版本号、层级与更新日志可读性

发布日期：2026-11-05

本版是 v0.5.0 的界面可读性小版本，集中处理标题栏版本标识、时间轴层级和更新日志字号。

## 改进

- **标题栏版本号**：电脑端品牌名“阑珊时刻”右侧显示 `v0.5.1` 小字，便于确认正在运行的构建。
- **时间轴当前时刻线**：当前时刻线保持在事件层上方，但位于留白提示卡下层；“这一天还没有被安排”卡片不再被线穿过。
- **更新日志弹窗**：桌面宽度提升到 980px，最大高度 88dvh；标题 38px、版本号 23px、正文 14px、日期 11px，行距和区块间距同步放大。手机端改为全宽、正文 14px，长更新仍可滚动阅读。

## 延续

- 桌面登录持久化、横向时间轴、六区拖拽、标签左右排序、首次启动默认布局。
- 手机周表 / 时间轴 / 添加 / 我的四栏，GitHub 头像、主题化提供商选择。
- 标题栏设置菜单、电脑端隐藏提醒、淡奶白日间模式与液态玻璃。

## 验证

- `npx tsc -b`、`npm run build`、`npm run lint`（0 error）。
- 桌面标题栏显示 `v0.5.1`；更新日志版本条目包含 v0.5.1–v0.2.0。
- 时间轴留白卡片位于当前时刻线上层。
- 更新日志桌面宽度约 980px，正文 14px、标题 38px。
- Android：`versionCode=13`、`versionName=0.5.1`。
