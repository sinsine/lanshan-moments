# v0.4.3 · 可停靠工作区与独立窗口修复

发布日期：2026-11-05

本版把桌面端从「固定四栏 + 自由拖动」改成了递归停靠工作区，并修复上一版反馈的三个拖拽问题。

## 修复

- **只有标题栏能拖动窗口**：在面板内容里点击、选择文字、输入、滚动不再触发窗口拖动，也不会出现幽灵/停靠预览。
- **拖到另一个标题栏会合并标签页**：拖动期间不再实时交换两个窗口的位置；指针经过目标标题栏时显示合并预览，松手后把当前标签组并入目标标签组。
- **拖出主窗口会生成独立窗口**：只有原生 Wails v3 壳返回成功后才从主布局移除面板；网页/开发环境自动退化为工作区浮动窗口，桥接失败时面板保留，不再“只是把小窗口关掉”。
- **独立窗口可拖回**：独立窗口使用原生标题栏拖动；拖到主窗口上方并松手后自动收回并重新停靠。标题栏的「收回」按钮和 Alt+F4 也会把面板还给主窗口。
- **窗口生命周期**：主窗口关闭时先关闭所有独立窗口再退出；独立窗口关闭不会留下空白主布局。
- **Service Worker**：不再缓存 `/api/*` 桥接请求，避免 `/api/state`、`/api/detach` 被旧缓存冻结；Wails 环境启动时会注销旧 Service Worker 并清理缓存，网页版缓存版本升级到 v2。

## 新工作区

- **递归停靠**：任意面板可向左/右/上/下分割，形成嵌套 Split 布局；不再局限于固定四栏。
- **标签组**：拖到另一个面板标题栏或内容中央合并为标签组，可点击切换、单个关闭、整组关闭。
- **停靠预览**：标题栏合并、内容四边分割、工作区边缘半屏、四角四分之一、顶部最大化都有独立高亮和文字提示。
- **最大化 / 全屏**：双击标题栏最大化/还原；右键菜单可最大化、全屏铺满或还原。最大化时其他面板保留状态但不再渲染。
- **浮动与独立窗口**：网页环境支持工作区内浮动窗口（可拖动、缩放、拖到边缘停靠、点图钉收回）；Wails v3 桌面壳创建真正的系统窗口。
- **独立窗口按钮**：收回主窗口、最小化、最大化/还原、全屏（F11）、关闭；主窗口与独立窗口通过 `localStorage` `storage` 事件同步日程与设置。
- **比例约束**：分隔条可拖动，双击复位 50%；子面板有最小像素宽度和 12% 比例下限。
- **布局持久化**：布局 JSON 带 `version: 3`，保存面板、标签组、嵌套分割、浮动窗口、最大化状态；旧版扁平布局在读取时迁移。自动保存，另提供手动快照/恢复。
- **快捷键**：`Ctrl+Shift+L` 保存布局快照，`Ctrl+Alt+R` 恢复默认四栏，`Ctrl+Shift+1~4` 切换面板，`Ctrl+Shift+M` 最大化/还原当前组。
- **多显示器与 DPI**：独立窗口创建/移动时按屏幕工作区换算并限制；位置完全移出屏幕后自动拉回；独立窗口记住上次位置和尺寸。
- **主窗口适配屏幕**：启动时把主窗口限制在屏幕工作区内，避免 1440×900 窗口在 900p 屏幕上顶部被裁掉。

## 仍未包含

- 一个原生独立窗口目前只承载一个面板；多标签组拖出时只把当前标签变成独立窗口，其余标签留在主窗口。
- 网页版的“浮动窗口”是工作区内浮动，不是系统原生窗口；系统窗口只在 Wails v3 壳中提供。
- 布局快照保存在本机 `localStorage`，暂不随 GitHub 同步。
- 时间轴/周概览在数据密集时仍可能出现内部滚动。
- Android 端继续使用手机周表/时间轴布局，不显示桌面停靠工作区。
