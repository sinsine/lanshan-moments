# v0.3.0 · 顶部菜单与可拖拽窗口

发布日期：2026-11-05

## 桌面端

- 取消左侧导航，改为顶部菜单栏：应用 / 编辑 / 窗口。
- 应用菜单：关于阑珊时刻、关于作者、检查更新、退出。
- 编辑菜单：撤销、重做、剪切、复制、粘贴、删除、全选，带快捷键提示。
- 窗口菜单：时间轴、周概览、整理箱、添加日程、设置，全部是可开关的窗口。
- 默认四个工作窗口铺满工作区：添加日程 / 整理箱 / 周概览 / 时间轴。
- 窗口可自由拖动、缩放、重叠；点击置顶，关闭后可从窗口菜单重新打开。
- 设置也改为浮动窗口，不再占用全屏遮罩。

## 手机端

- 手机端改为类似课程表的周视图：七列日期、08:00–22:00 时间轴、事件块、顶部周切换。
- 底部改为三个栏目：周表 / 时间轴 / 我的。
- 打开 Android 应用后隐藏状态栏；保留手势导航。
- 全局移除移动端点击时的蓝色高亮和焦点框。

## 模型接口

- 增加提供商预设：DeepSeek（默认）、OpenAI、通义千问、Moonshot、智谱、SiliconFlow、OpenRouter、Gemini、Ollama。
- 输入 Key 后可点“获取模型”，从接口返回的模型列表里点选。
- API Key 改存本机 `localStorage`，关闭应用后仍保留。
- 本轮不包含 Anthropic Messages API 适配；默认模型为 DeepSeek。

## 构建

- Windows portable EXE（Wails v2）
- Android debug APK（Capacitor 8，versionCode 5 / 0.3.0，targetSdk 36）
