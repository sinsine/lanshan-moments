# v0.4.1 · 字体、比例与主题

发布日期：2026-11-05

- 桌面平铺窗口支持拖动分隔条调整左右/上下比例。
- DeepSeek 默认接口地址改为 `https://api.deepseek.com`，并自动迁移旧设置里的 `/v1` 地址。
- Windows 构建改用 `-H windowsgui`，启动时不再先出现终端窗口。
- 全软件改用 HarmonyOS Sans SC（Light / Regular / Medium / Bold），字体随安装包内置。
- 默认主题改为日间模式；已有用户仍可在右上角切换。
- 小窗口内容增加紧凑布局，优先保证主要按钮与输入区可见。
- 独立窗口、拖出/拖回停靠、顶部窗口控制继续保留。

## 未包含

- 窗口标签页合并（AE 式）尚未实现。
- 所有面板完全无滚动仍需继续压缩布局。

## 构建

- Windows: `lanshan-moments-0.4.1-windows-amd64.exe`（Wails v3）
- Android: `lanshan-moments-0.4.1-android-universal.apk`（versionCode 8 / 0.4.1）
