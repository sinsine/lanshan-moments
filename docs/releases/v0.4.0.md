# v0.4.0 · Wails v3 与平铺多窗口

发布日期：2026-11-05

## 桌面窗口

- Windows 桌面壳迁移到 **Wails v3.0.0**，支持原生多窗口。
- 主窗口四个面板改为平铺布局，平铺状态无圆角。
- 拖动面板标题栏时：
  - 跟随鼠标的标题 ghost；
  - 目标槽位虚线预览；
  - 其他面板实时回流补位；
  - 松手后动画落位。
- 面板可拖出工作区，调用 v3 桥接创建独立原生窗口；关闭独立窗口后主窗口恢复面板。
- 独立窗口只渲染对应面板，圆角、无边框，顶部为拖动区。
- 主窗口与独立窗口通过 `localStorage` 的 `storage` 事件同步日程与设置。
- 顶部导航保留应用/编辑/窗口菜单与最小化/最大化/关闭。

## 其他

- GitHub API、设备码授权、外部浏览器打开通过 v3 HTTP 桥接，不再依赖 Wails v2 的 `window.go`。
- 登录 Token 持久化、无演示日程、同步高级项折叠继续保留。
- DeepSeek 401 已加空 Key 拦截与明确提示；真实无效 Key 仍会由 DeepSeek 返回 401。

## 构建

- Windows: `release/lanshan-v4.exe`（Wails v3，无边框多窗口）
- Android: `release/lanshan-debug.apk`（versionCode 7 / 0.4.0，targetSdk 36）
