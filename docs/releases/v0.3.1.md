# v0.3.1 · 登录持久化与窗口修正

发布日期：2026-11-05

- 修复「获取模型」在未填 API Key 时直接请求导致 401：现在会先拦截，并针对 401 给出 Key 无效/与提供商不匹配的提示。
- 设置 → 多设备同步：网页登录按钮以下的手动配置全部收进默认折叠的「手动配置与高级选项」。
- 移除时间轴头部的「本周」按钮；周概览仍保留独立的「回到本周」。
- 移除默认演示日程；首次安装为空时间轴，旧版本遗留的 `evt_seed_*` 演示事件也会在加载时清理。
- GitHub 登录令牌改为本机 `localStorage` 持久化，关闭/更新应用后不再丢失。
- Windows 改为无边框窗口，顶部导航集成最小化 / 最大化 / 关闭，并作为窗口拖拽区；移除原生标题栏。
- 桌面窗口默认平铺且无圆角；拖动后切换为浮动窗口并恢复圆角；窗口随主窗口尺寸变化重新铺满。
- 窗口拖动不再限制在工作区边界内。

Windows：`lanshan.exe`；Android：`lanshan-debug.apk`（versionCode 6 / 0.3.1）。
