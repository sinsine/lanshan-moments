# v0.2.2 · 内置 GitHub OAuth Client ID

发布日期：2026-11-05

- 将公开 OAuth App Client ID 写入默认配置；其他用户安装后不需要再手动填写。
- 已用真实 Client ID 请求 GitHub 设备码接口，返回 200 并拿到 `user_code`，确认 Client ID 有效、Device Flow 已开启。
- 用户流程仍需要：点登录 → 在 GitHub 页面确认授权 → 选择/新建私有仓库。GitHub 的 Device Flow 不会跳过授权确认。
- 浏览器 PWA 仍受 CORS 限制；网页版用访问令牌，Windows/Android 原生端用设备码。

构建：Windows portable EXE + Android debug APK（versionCode 4 / 0.2.2）。
