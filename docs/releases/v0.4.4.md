# v0.4.4 · 标签、思考与液态玻璃

发布日期：2026-11-05

本版处理桌面拖拽、DeepSeek JSON、云同步、独立窗口收回、AI 设置、更新检查、液态玻璃、更新日志与日间配色。

## 修复与改进

- **标签页单独拖动**：拖动标签组中的某个标签时，只移动该标签对应的面板；当前置顶标签不会再被整组带走。拖到另一个标题栏合并、拖到四边分割、拖出转独立窗口都按单个标签处理。
- **DeepSeek 思考强度**：模型设置新增“关闭 / 低 / 高 / 最高”。关闭时发送 `thinking: { type: "disabled" }`，不再发送 `reasoning_effort`；开启时按 `low` / `high` / `max` 映射。
- **JSON 与多日程**：输出上限提高到 8192 tokens；加强 system prompt，要求 `events` 列出文本中的全部日程。新增平衡括号提取、尾逗号容错、根数组兼容、思考过程/截断/空内容的具体报错，以及开启思考时失败自动关闭思考重试一次。
- **云同步 SHA 修复**：上传前预检现有 `schedule.json` 的 blob SHA；当配置分支上没有文件时回退到仓库默认分支读取，避免 GitHub 返回 `"sha" wasn't supplied`。
- **独立窗口收回**：判定从“标题落在主窗口内”收窄为“标题落在主窗口中央 64% 区域且窗口至少一半重叠”；主窗口和独立窗口都会显示液态玻璃停靠预览动画，松手后才收回。
- **AI 设置交互**：API Key 字段移到模型之前；输入 Key 后 850ms 防抖自动获取模型；点击模型后自动发起一次真实连接测试，并显示“连接成功”或错误。保留手动获取/测试按钮。
- **检查更新 403**：原生端改为走 Go 的 GitHub 代理并携带已保存 Token；403 时提示 GitHub API 速率限制，而不是只显示状态码。
- **液态玻璃**：整理箱、设置、事件详情、GitHub 连接、检查更新、更新日志和移动端弹层统一增加模糊、饱和度、玻璃高光与内阴影；整理箱增加顶部环境反光。
- **更新日志**：应用菜单新增「更新日志」，位于“检查更新”与“退出”之间，并在更新日志与退出之间加入分割线。弹窗显示版本时间轴、日期、当前版本徽标和 Release 直达链接。
- **淡奶白日间模式**：日间背景由纯白改为 `#faf6eb` 淡奶白，配套调整面板、玻璃、输入框、边框、阴影与液态背景色。

## 仍未包含

- 一个原生独立窗口仍只承载一个面板；多标签组拖出时只把当前标签独立，其余标签留在主窗口。
- 网页版浮动窗口仍是工作区内浮动，不是系统原生窗口。
- 布局快照保存在本机 `localStorage`，暂不随 GitHub 同步。
- Android 端继续使用手机周表/时间轴布局，不显示桌面停靠工作区。
