# v0.2.0 · 本周与两端

发布日期：2026-11-04

这是“阑珊时刻”从 Web Demo 走向 Windows / Android 初版的一版。

## 新增

- **本周概览**：七列查看周一至周日；每个日程显示开始–结束、标题、地点；待安排单独列出；支持上一周/下一周/回到本周。
- **墨辰视觉**：黑白灰、液态玻璃、日间/夜间双主题；四个悬浮玻璃面板；周视图自动收起采集/整理栏。
- **日程必填**：开始时间、结束时间、地点；未补齐不能写入时间轴。地点可以明确选择“待定”。
- **AI 澄清问题**：地点未知、持续时间不确定、是否需要参加时，AI 生成选项 + 自由输入；默认推断的结束时间也会追问。
- **图形化 GitHub 连接**：OAuth Device Flow（设备码）+ 访问令牌向导；自动读取私有仓库、创建同步仓库；Windows/Android 通过原生代理绕过 CORS。
- **Windows 端**：Wails v2 + Go + WebView2，便携 EXE。
- **Android 端**：Capacitor 8 + JDK 21 + SDK 36，debug APK。
- **Android 通知**：提前 10 分钟本地提醒，提供精确闹钟授权入口和 ColorOS 设置说明。
- **多语言基础**：`src/i18n.ts` + 模块级 COPY；当前仍只发布简体中文。

## 文件

- Windows：`lanshan.exe`
- Android：`lanshan-debug.apk`

## 测试

- 网页：Edge 桌面 1440×900、移动 390×844、深/浅主题、PWA 离线重载。
- AI：mock OpenAI 兼容接口 + 图片输入；未用真实 Key 做线上回归。
- GitHub：mock Contents API + mock Device Flow；未用真实 OAuth App/仓库做线上回归。
- Windows：Wails 构建并启动，窗口标题“阑珊时刻”，WebView 正常渲染。
- Android：Capacitor 工程构建；测试机一加 Ace 6T / ColorOS 16 待安装验证。

## 已知问题

- 浏览器 PWA 不能完成 GitHub Device Flow（CORS）；请用 Windows/Android 或访问令牌。
- OAuth Client ID 需要开发者创建后填入设置；详情见 README。
- Android 桌面小组件、iOS/macOS/HarmonyOS 原生端尚未实现。
- 精确闹钟受 ColorOS 后台限制，不能保证 100% 准点。
- 网页端仍用 localStorage；生产版将迁移 IndexedDB/SQLite。
